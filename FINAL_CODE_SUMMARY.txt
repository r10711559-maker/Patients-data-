FILE 1: lib/supabase-client.ts
================================================================================

Location: /vercel/share/v0-project/lib/supabase-client.ts

Code:
-----
import { createBrowserClient } from "@supabase/ssr"

let supabaseClient: ReturnType<typeof createBrowserClient> | null = null

export function getSupabaseClient() {
  if (typeof window === "undefined") {
    return null
  }

  if (!supabaseClient) {
    supabaseClient = createBrowserClient(
      process.env.NEXT_PUBLIC_SUPABASE_URL!,
      process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
    )
  }

  return supabaseClient
}

Purpose:
- Creates singleton Supabase client
- Only runs in browser (client-side)
- Uses environment variables for URL and key
- Lazy initialization on first access

FILE 2: lib/db-operations.ts
================================================================================

Location: /vercel/share/v0-project/lib/db-operations.ts

Key Functions:

addPatient(patientData: Patient)
- Generates unique patient_id (PAT-[timestamp]-[random])
- Inserts into patients table
- Returns inserted patient object
- Used when "Register Patient" clicked

getPatients()
- Fetches all patients from Supabase
- Ordered by created_at DESC (newest first)
- Returns array of Patient objects
- Called on app load and after each registration

searchPatients(searchTerm: string)
- Searches by name, patient_id, or mobile
- Case-insensitive (ilike operator)
- Returns matching patients
- Used in search bar

updatePatient(patientId: string, patientData: Partial<Patient>)
- Updates patient information
- Called when Edit Patient clicked and form submitted
- Updates only provided fields

addBill(billData: Bill)
- Creates billing record
- Auto-called after patient registration
- Default amount: 500, status: pending

Interfaces:
- Patient { id, patient_id, name, age, gender, mobile, address, test_name, created_at, updated_at }
- Bill { id, patient_id, test_id, amount, status, bill_date, payment_date, created_at }
- TestRecord { id, patient_id, test_name, test_date, results, notes, created_at }
- Report { id, patient_id, test_id, report_data, report_date, created_at }

All functions:
- Use getSupabaseClient() to get Supabase instance
- Include error handling with console.error
- Throw errors that propagate to UI
- Support TypeScript with proper interfaces

FLOW SUMMARY: How Registration Works
================================================================================

1. User Opens App
   → useEffect runs loadPatients()
   → Fetches from Supabase patients table
   → Displays in list (empty on first load)

2. User Fills Form (6 fields)
   → Each input updates formData state via handleChange()
   → Real-time form validation

3. User Clicks "Register Patient"
   → handleSubmit() runs
   → Validates all 6 fields (shows error if any empty)
   → Calls addPatient(formData)

4. addPatient() Function
   → Generates unique patient_id (PAT-[timestamp]-[random])
   → Inserts into Supabase patients table
   → Returns inserted patient object

5. Auto Billing
   → If patient inserted successfully
   → Calls addBill() with auto-created bill record
   → Bill: amount=500, status=pending, patient_id=inserted_patient_id

6. Success & Cleanup
   → Shows toast: "Patient Registered Successfully"
   → Clears form fields
   → Calls loadPatients() to refresh list

7. Patient Appears in List
   → getPatients() fetches updated list from Supabase
   → New patient displays with all data
   → Shows registration date
